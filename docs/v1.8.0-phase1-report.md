## 1. Alterações de Schema (`database.py` — Migração `v11 → v12`)

A função `_apply_migration_v12(cursor)` foi implementada com idempotência total (`PRAGMA table_info` + `IF NOT EXISTS`), transação atômica e backup pré-migração automático (`lectoria_pre_migration_v11_to_v12.db.bak`):

1. **Tabela `highlights`**:
   - `visibility TEXT NOT NULL DEFAULT 'private' CHECK (visibility IN ('private', 'public'))`
   - `epub_cfi TEXT`
   - `chapter_label TEXT`
   - `updated_at TIMESTAMP` (preenchido retroativamente com `COALESCE(created_at, CURRENT_TIMESTAMP)` nos registros existentes)
2. **Tabela `notes`**:
   - `visibility TEXT NOT NULL DEFAULT 'private' CHECK (visibility IN ('private', 'public'))`
   - `epub_cfi TEXT`
   - `chapter_label TEXT`
3. **Tabela `page_drawings`**:
   - `visibility TEXT NOT NULL DEFAULT 'private' CHECK (visibility IN ('private', 'public'))`
   - `created_at TIMESTAMP` (preenchido retroativamente com `COALESCE(updated_at, CURRENT_TIMESTAMP)` nos registros existentes)
4. **Nova Tabela `bookmarks` (Marcadores Pessoais de Leitura)**:
   - `id TEXT PRIMARY KEY`
   - `book_id TEXT NOT NULL REFERENCES books(id) ON DELETE CASCADE`
   - `user_id INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE`
   - `page INTEGER NOT NULL DEFAULT 1 CHECK (page >= 1)`
   - `epub_cfi TEXT NULL`
   - `chapter_label TEXT NULL`
   - `label TEXT NOT NULL DEFAULT ''`
   - `created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP`
   - `updated_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP`
5. **Índices Criados**:
   - `idx_highlights_book_vis_page ON highlights(book_id, visibility, page)`
   - `idx_highlights_book_user_page ON highlights(book_id, user_id, page)`
   - `idx_highlights_book_cfi ON highlights(book_id, epub_cfi)`
   - `idx_notes_book_vis_page ON notes(book_id, visibility, page)`
   - `idx_notes_book_user_page ON notes(book_id, user_id, page)`
   - `idx_notes_book_cfi ON notes(book_id, epub_cfi)`
   - `idx_drawings_book_vis_page ON page_drawings(book_id, visibility, page)`
   - `idx_drawings_book_user_page ON page_drawings(book_id, user_id, page)`
   - `idx_bookmarks_book_user_page ON bookmarks(book_id, user_id, page)`
   - `uq_bookmarks_book_user_pos ON bookmarks(book_id, user_id, page, COALESCE(epub_cfi, ''))`

> **Decisão Aprovada Cumprida**: Apenas `'private'` e `'public'` foram implementados; não foi criado `club_id` nem a modalidade `'club'`.

## 2. Serviços Implementados e Evoluídos (`annotations_service.py`)

### 2.1 Verificação de Acesso Canônico ao Livro (`_verify_book_access`)
- Associa e valida permissões estritamente pelo `books.id` canônico.
- Verifica se o livro existe, se `is_missing == 0`, se a fonte (`library_sources`) está ativa (`is_active == 1`) e se a conta do usuário está ativa (`users.is_active == 1`).

### 2.2 Operações de Destaques (`highlights`)
- `create_highlight(...)`: suporta tanto PDF (`rects` obrigatório quando `epub_cfi` ausente) quanto EPUB (`epub_cfi` validado no formato `epubcfi(...)` até 1.024 caracteres, `rects` opcional `[]` e `chapter_label` até 300 caracteres). Nasce como `'private'` por padrão.
- `get_highlight_by_id(highlight_id, user_id)`: proteção anti-IDOR (retorna `AnnotationNotFoundError` se o destaque for `'private'` e pertencer a outro usuário).
- `get_highlights(book_id, page=None, user_id=1, scope='mine', epub_cfi=None, search=None, sort_by='position', limit=None, offset=0)`:
  - Escopos padronizados: `mine`, `public`, `all_visible` (sem duplicações).
  - Enriquecimento de autoria pública (`author_display_name`, `author_avatar_color`, `is_own`, `visibility`) em consulta única via `LEFT JOIN`.
- `set_highlight_visibility(highlight_id, visibility, user_id)`: permite ao autor publicar (`'public'`) ou revogar (`'private'`); bloqueia terceiros com `AnnotationPermissionError` / `AnnotationNotFoundError`.
- `delete_highlight(highlight_id, user_id)`: restrito ao autor.

### 2.3 Operações de Notas (`notes`)
- `create_note(...)`: suporta notas PDF e EPUB CFI (`epub_cfi`, `chapter_label`), herdando automaticamente `epub_cfi` e `chapter_label` quando vinculada a um destaque EPUB do próprio usuário. Privada por padrão.
- `get_note_by_id(note_id, user_id, allow_public=False)`: isolamento estrito contra leitura indevida de notas privadas de terceiros.
- `get_notes(...)`: suporte completo aos escopos `mine`, `public` e `all_visible`, filtro por `page` ou `epub_cfi`, busca textual, ordenação (`position` / `recent`) e paginação (`limit` / `offset`).
- `update_note(...)` e `set_note_visibility(...)`: restritos exclusivamente ao autor.

### 2.4 Operações de Desenhos Vetoriais (`page_drawings`)
- `save_page_drawing(book_id, page, strokes, user_id, visibility=None)`: novos desenhos nascem `'private'`; atualizações subsequentes de traços preservam a visibilidade atual caso `visibility` não seja passada explicitamente.
- `get_page_drawing(book_id, page, user_id)`: retorna o desenho do próprio usuário na página.
- `get_page_drawings(book_id, page=None, user_id=1, scope='mine', ...)`: lista desenhos conforme o escopo.
- `get_page_drawings_bundle(book_id, page, user_id)`: retorna `{"page": page, "own_drawing": ..., "public_drawings": [...]}` separando o desenho editável do próprio leitor dos desenhos públicos somente-leitura de outros usuários.
- `set_page_drawing_visibility(book_id, page, visibility, user_id, drawing_id=None)`: altera visibilidade exclusivamente dos desenhos do próprio autor.
- `delete_page_drawing(book_id, page, user_id)`: apaga somente o desenho do próprio usuário na página.

### 2.5 Operações de Marcadores Pessoais (`bookmarks`)
- `create_bookmark(book_id, user_id, page=1, epub_cfi=None, chapter_label=None, label='')`: cria ou atualiza marcador na mesma posição `(book_id, user_id, page, COALESCE(epub_cfi, ''))` sem gerar duplicatas.
- `list_bookmarks(book_id, user_id, limit=None, offset=0)` e `delete_bookmark(bookmark_id, user_id, book_id=None)`: estritamente privados por usuário.

### 2.6 Resumo Consolidado (`get_book_annotations_summary`)
- Suporta `scope` (`mine`, `public`, `all_visible`), `search`, `sort_by` (`position`, `recent`), `limit` e `offset`.
- Retorna `drawing_pages` leves (sem trafegar `strokes_json` de todas as páginas do livro) e `bookmarks` sempre restritos ao próprio usuário.

## 3. Segurança em Importação e Exportação (`export_service.py`)

- **Exportação (`export_book_annotations_json` e `export_book_annotations_markdown`)**:
  - Filtra explicitamente por `scope="mine"`, garantindo que exportações pessoais jamais incluam anotações públicas ou privadas de outros usuários.
  - Exporta `epub_cfi`, `chapter_label` e `bookmarks` mantendo compatibilidade com o formato `"version": "1.0"`.
- **Importação (`validate_import_payload`, `preview_import_annotations`, `apply_import_annotations`)**:
  - Ignora qualquer `user_id` ou `visibility: "public"` vindo no JSON importado: **todos os itens importados são gravados como `visibility = 'private'` e vinculados ao `user_id` autenticado**.
  - Impede que uma nota importada referencie um `highlight_id` pertencente a outro usuário.
  - Gera novos UUIDs para todos os itens importados e nunca sobrescreve desenhos ou anotações de terceiros.
