## 2. Falhas Investigadas e Corrigidas na Fase 6

1. **Dependência de rede externa em `tests/test_audit_v140.py`**:
   - **Causa raiz**: `test_api_rate_limiting_and_cached_lookup` e `test_nonexistent_isbn_negative_caching` executavam requisições HTTP reais contra `https://openlibrary.org` via `OpenLibraryClient.lookup_isbn()` -> `_safe_http_get_json()`. Sob latência/timeout da API externa, o lookup retornava `None` sem gravar cache negativo `404`.
   - **Correção**: Substituída a camada de transporte `urllib.request.urlopen` via `monkeypatch` com respostas simuladas HTTP `200` e `HTTPError 404`, mantendo 100% da execução real do rate limiter, parser, cache SQLite positivo e cache negativo (`404`).
2. **Ordenação lógica EPUB (`compareEpubCfi()`)**:
   - **Causa raiz**: No fallback numérico quando `ePub.CFI.prototype.compare` não estiver disponível, dígitos dentro de *ID assertions* (`[chap10]`) podiam interferir nos passos estruturais.
   - **Correção**: Remoção de `[...]` (`replace(/\[[^\]]*\]/g, "")`) antes da extração de passos numéricos, priorizando `ePub.CFI.prototype.compare` quando carregado.
3. **Overflow horizontal em `1366x768` (`.reader-header`)**:
   - **Corrigido na Fase 5 / validado na Fase 6**: Compactação responsiva até `1440px` em `static/css/style.css` garantindo `scrollWidth <= clientWidth` nas 7 resoluções (`360px`, `390px`, `768px`, `820px`, `1024px`, `1366px`, `1920px`).

## 4. Avaliação de Segurança, Performance e Compatibilidade

- **Segurança**: Autenticação obrigatória (`401`), CSRF (`403`), `ConfigDict(extra="forbid")` (`422`), anti-IDOR entre múltiplos perfis (`Alice`, `Bob`, `Charlie` / fonte inativa / usuário desativado), `Cache-Control: private, no-store`, `allowScriptedContent: false` no EPUB e sanitização via `textContent` / `escapeHtml()`.
- **Performance**: Streaming HTTP Range (512 KB) preservado no PDF, virtualização de slots no modo contínuo, carregamento de desenhos sob demanda por página, paginação incremental de 50 itens no Caderno de Estudos, zero consultas N+1 e zero dependências de SGBD externo (adequado para VPS com 4 GB de RAM).
- **Compatibilidade**: Regressão integral da v1.7.0 (Leitura Compartilhada, Clubes, Biblioteca, Filtros Taxonômicos, Progresso e Importação/Exportação) aprovada.
