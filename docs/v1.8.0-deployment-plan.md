# Lectoria v1.8.0 — Plano Controlado de Release e Deployment

> **Aviso de Governança**: Este plano documenta os passos a serem executados **somente após autorização explícita do mantenedor**. Nenhuma etapa abaixo foi executada automaticamente.

---

## 1. Pré-requisitos e Risco de CI/CD Identificado

- Confirmar `git status` limpo e revisão final do diff `main..feature/v1.8.0-reader-experience`.
- **Atenção ao Workflow `.github/workflows/publish.yml`**: O workflow executa `docker/build-push-action` e sobrescreve `ghcr.io/nosremekk/lectoria:stable` tanto em `push` para `main` quanto em `push` de tags `v*`. Portanto, **não faça push para `main`** antes de concluir a revisão final.

---

## 2. Sequência Recomendada de Publicação (Git + GHCR)

1. **Commit consolidado na branch `feature/v1.8.0-reader-experience`**:
   - Adicionar explicitamente os arquivos da v1.8.0 (sem bancos `.db`, backups ou arquivos temporários) e commitar com mensagem clara (ex.: `feat: release Lectoria v1.8.0 reader experience and social annotations`).
2. **Merge controlado em `main`**:
   - Atualizar `main` (`git fetch origin && git checkout main && git pull --ff-only origin main`), realizar o merge da branch `feature/v1.8.0-reader-experience` e enviar `git push origin main`.
3. **Tag oficial `v1.8.0`**:
   - Criar tag anotada `git tag -a v1.8.0 -m "Lectoria v1.8.0"` e enviar `git push origin v1.8.0`.
4. **Acompanhamento de CI & GHCR**:
   - Verificar execução verde dos workflows `CI` e `Publish Docker Image (GHCR)` no GitHub Actions.
   - Confirmar o digest publicado para `ghcr.io/nosremekk/lectoria:v1.8.0`, `:1.8.0` e `:stable`.

---

## 3. Backup e Atualização Segura da VPS (4 GB RAM)

1. **Backup obrigatório pré-atualização** (antes de subir o novo container):
   ```bash
   docker compose stop lectoria
   python3 scripts/backup.py
   cp data/lectoria.db "backups/lectoria_pre_v180_$(date +%Y%m%d_%H%M%S).db"
   ```
   *(Nota: na primeira inicialização da v1.8.0, `database.init_db()` também cria automaticamente `lectoria_pre_migration_v11_to_v12.db.bak`.)*
2. **Atualização controlada da imagem**:
   ```bash
   docker compose pull lectoria
   docker compose up -d lectoria
   ```
3. **Smoke tests pós-deploy**:
   - Verificar `GET /api/health` e `GET /api/auth/status` (`"version": "1.8.0"`).
   - Abrir um PDF e um EPUB, confirmar renderização, criação de nota privada e verificação de `visibility = 'private'` em anotações antigas.

---

## 4. Plano de Rollback

Em caso de anomalia crítica na VPS:
1. Parar o container: `docker compose stop lectoria`.
2. Restaurar o backup SQLite v11 criado antes da atualização:
   `python3 scripts/backup.py --restore backups/lectoria_pre_v180_...db` (ou o `.bak` pré-migração gerado automaticamente).
3. Fixar a imagem anterior no `docker-compose.yml` (`ghcr.io/nosremekk/lectoria:v1.7.0`) e subir novamente: `docker compose up -d lectoria`.
